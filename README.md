# Mom & Dad · 26th Anniversary

A standalone anniversary keepsake made for Mom and Dad, from Tanvi & Kashvi.

Open `dist/index.html` directly, or serve the `dist` directory with any static server. No build or dependencies are required. The optional Google Fonts fall back to local serif and sans-serif fonts when offline.

Features: responsive burgundy-and-gold design, interlocking ring artwork, 26 thank-you notes, an accessible letter dialog, and a confetti celebration with reduced-motion support.

Personalize the names and letter in `dist/index.html`; the 26 notes are in `dist/anniversary.js`. No anniversary date or photos have been assumed.

Tulu touch: **ಮೋಕೆ / Moke — love**. References: https://glosbe.com/en/tcy/love and https://www.easytulu.com/2016/03/?m=0 . The English messages are original anniversary wishes, not claimed translations of full Tulu sentences.

## Vercel deployment

For a separate anniversary project, set Root Directory to `mom-dad-26th-anniversary`, Framework Preset to Other, leave Build Command empty, and use `dist` as Output Directory. The folder’s `vercel.json` supplies the build and output settings. The repository-root Vercel configuration still serves the existing wedding site.
